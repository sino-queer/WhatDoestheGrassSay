# What Does the Grass Say

A static art exhibition guide, built with React + Vite.

Live site: https://sino-queer.github.io/WhatDoestheGrassSay/

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Build for production:
   `npm run build`

Deployed automatically to GitHub Pages via GitHub Actions on every push to `main`.
